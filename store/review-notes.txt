REVIEW ENVIRONMENT

Retro-Amiga is a hardware emulator for the Commodore Amiga (1985) under Guideline 4.7. No account, login, credentials or files are needed. Launch the app, tap Finish setup, and the emulator boots on the bundled AROS ROM and the DEMO.ADF disk. To evaluate with a real Kickstart, put one (e.g. kick31.rom) in the app's Documents folder via the Files app and use Settings > Run setup again. Commodore's ROMs are Cloanto's copyright (Amiga Forever) and are NOT included.

THE APP HAS NO NETWORK CODE. The iOS binary contains no HTTP client, no socket calls and no networking of any kind; the emulated Amiga has no network interface. No accounts, payments, analytics, advertising, AI or third-party data; it collects nothing. Privacy policy: https://www.crownparkcomputing.com/privacy

The camera, photo library, location and Bluetooth usage strings in Info.plist exist only because the bundled file picker and SDL link those frameworks and upload validation demands a string for each (ITMS-90683). The app never requests those permissions and has no feature using them.

The Music tab plays tracker modules the user imports. It ships with none and lists twenty well-known Amiga tunes as a reading list, each marked "not on this device" until the user adds it; nothing is downloaded.

No regional differences; free everywhere; English (UK) only. Verified on the iOS Simulator; device testing via TestFlight.

WHAT CHANGED SINCE THE 5.6 REJECTION OF 28 AUGUST

We found the cause and removed it. Our earlier notes said the app had no network features, but the embedded emulator core still contained UAE's bsdsocket.library emulation over a user-mode TCP/IP stack (SLIRP), and the app enabled it in every machine configuration, so Amiga software inside the emulator had internet access we had described nowhere. Not deliberate, but a real gap between the binary and our notes. In this build that code is compiled out of the iOS core (no socket imports remain), and the configuration no longer enables it. The Music tab no longer shows a download glyph on absent tunes. These notes now carry the full 4.7.4 index and explain the permission strings, so nothing in the binary is undeclared.
